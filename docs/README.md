## Contributing to Documentation

When updating documentation:
1. Keep language clear and concise
2. Include examples and diagrams where helpful
3. Update cross-references when adding new sections
4. Maintain consistent formatting and style

## Documentation Standards

- Use Markdown format for all documentation
- Include table of contents for documents > 500 lines
- Provide code examples with syntax highlighting
- Use mathematical notation with LaTeX when needed
- Include references to external sources
